      What runs here

      Honest limits.

      • Python 3 — full standard library, plus numpy and pandas on demand. First run downloads the engine, then it is cached.
      • JavaScript — runs instantly, no download.
      • C and C++ — run here through a JavaScript interpreter. Core language works: variables, arrays, pointers, loops, functions, structs, printf and cout. It does not support classes, namespaces, templates or the STL.
      • Java — needs a JVM, which no browser has. See the Java section in Learn from Basics for trace-the-output practice (auto-checked), a local setup guide, and where to practise with a real compiler.
      • No file system, no network, no pip install of arbitrary packages.
      • Code is saved in this browser alongside your tasks, and is included in your JSON backup.

        Back up to GitHub automatically

        Saves your whole tracker to a private GitHub Gist, so your laptop and phone can share the same data.

        Use a token with only the gist scope. It is stored in this browser and sent only to api.github.com — but never paste a token into the HTML file you push to your repo.
        Not connected
        How to create the token
        1. GitHub → click your avatar → Settings
        2. Left sidebar, all the way down → Developer settings
        3. Personal access tokens → Tokens (classic) → Generate new token (classic)
        4. Note: LearnTrack backup · Expiration: 90 days or No expiration
        5. Tick only the gist checkbox — nothing else
        6. Generate, copy the token, paste it above, click Back up now
        7. Copy the Gist ID that appears — paste it on your other devices to sync them

        How the tracker works

        A quick tour.

        • Plan by date. Give a question any date — tomorrow, Friday, next Monday. It moves into Today by itself when that date arrives.
        • No deadlines. Nothing is ever late. Come back after a week away and pick up exactly where you stopped.
        • No penalties. Take a week off and nothing changes — your XP, streak record, badges and completed work all stay exactly as they were.
        • Timestamps. Ticking a box stores the exact date and time forever.
        • Sessions. Start/stop a timer per question; minutes feed the topic table and weekly report.
        • Streaks. A day counts when you complete a question or save a journal entry.
        • Portfolio ready. One HTML file — no build step, no dependencies. Drop it anywhere in your portfolio repo.
