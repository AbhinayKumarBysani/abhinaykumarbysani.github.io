      Why this works

      The forgetting curve, in short.

      • You forget roughly 70% of new material within a week unless you revisit it.
      • Re-solving at 1 day, 7 days and 30 days moves it into long-term memory.
      • Re-solve from a blank file — recognising your old code is not the same as recalling it.
      • A revision takes 5 minutes. It is the cheapest learning in this whole app.
      • Any task card also has a schedule revision option if you want to add one manually.

      What runs here

      Honest limits.

      • Python 3 — full standard library, plus numpy and pandas on demand. First run downloads the engine, then it is cached.
      • JavaScript — runs instantly, no download.
      • Anything else (C, C++, Java, SQL) — the editor saves your code, but it cannot execute it here.
      • No file system, no network, no pip install of arbitrary packages.
      • Code is saved in this browser alongside your tasks, and is included in your JSON backup.

        How the tracker works

        A quick tour.

        • Plan by date. Give a question any date — tomorrow, Friday, next Monday. It moves into Today by itself when that date arrives.
        • Out of track is automatic. Planned date passed and still open → flagged red. No manual marking.
        • Recovered items. Finish a missed question later and it is logged as recovered, keeping both the planned and actual dates.
        • Timestamps. Ticking a box stores the exact date and time forever.
        • Sessions. Start/stop a timer per question; minutes feed the topic table and weekly report.
        • Streaks. A day counts when you complete a question or save a journal entry.
        • Portfolio ready. One HTML file — no build step, no dependencies. Drop it anywhere in your portfolio repo.
